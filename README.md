# 🦊 白狐影视 (White Fox TV) - 终极多端部署版

一个功能强大、性能卓越的开源影视项目。支持 **Cloudflare Pages**、**Vercel**、**Docker** 以及 **手动上传**。

---

## ⚠️ 注意事项

> **重要说明**：若页面不能正常播放，请进入下载页面观看。

## ✨ 核心特性

- 📺 **全站搜索**: 集合 20+ 资源站结果，一键找片。
- 🎬 **全能播放**: 分辨率覆盖 **240P - 1080P** (默认 **480P**)，支持 **跳过片头**。
- 🔒 **安全访问**: 内置密码锁，保护访问私密。
- 🌓 **双色模式**: 丝滑切换白天/夜间主题。
- ☁️ **云端同步**: 适配 Cloudflare D1，历史与设置永不丢失。

## 🚀 部署方案 (选一种最适合你的)

### 1. Cloudflare Pages 自动部署 (推荐)
- **步骤**: GitHub Fork 本项目 -> CF Pages 绑定仓库。
- **构建设置**: 命令 `npm run build`，目录 `dist`。

### 2. Cloudflare Pages 手动上传部署 (无须 GitHub)
- **适合场景**: 不想使用 GitHub，或想快速预览。
- **步骤**:
  1. 下载本项目，在本地运行 `npm run build` 生成 `dist` 文件夹。
  2. 在 Cloudflare Pages 选择 **“上传资产” (Direct Upload)**。
  3. 将 `dist` 文件夹内的 **所有文件** 拖入上传框即可。
- **注意**: 这种方式同样支持 D1 绑定和 Edge Functions 代理。

### 3. Vercel 部署
- **步骤**: GitHub Fork 本项目 -> Vercel 导入仓库 -> 设置 `PASSWORD` 环境变量。

### 4. Docker 部署 (NAS/自服)
```bash
docker build -t white-fox .
docker run -d -p 3000:3000 -e PASSWORD=your_pass white-fox
```

## ❓ 常见问题排查 (部署必看)

| 现象 | 原因 | 解决 |
| :--- | :--- | :--- |
| **视频播放失败** | 跨域(CORS)限制 | 必须部署在 CF/Vercel 或 Docker 以使用内置代理。 |
| **刷新 404** | 路由未重定向 | 确保 `_redirects` (CF) 或 `vercel.json` (Vercel) 已在根目录。 |
| **无法同步/保存** | D1 未绑定 | 在 CF 控制台手动绑定 D1 数据库到 `DB` 变量。 |
| **手动上传后无功能** | 上传目录错误 | 必须上传 `dist` 文件夹**内部**的内容，而不是上传 `dist` 文件夹本身。 |
