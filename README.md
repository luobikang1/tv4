# 🦊 白狐影视 (White Fox TV) - 部署全攻略

一个为 **Cloudflare Pages** 和 **Vercel** 深度优化的影视面板项目。功能同步月亮TV，支持高清播放与数据同步。

---

## 📦 核心依赖

+-----------------------------------------------------------+
| **框架**: React 18 + Vite + Tailwind CSS                  |
| **播放**: ArtPlayer (支持 m3u8 / HLS)                     |
| **功能**: 支持 **360P** 低分辨率调节，保护流量           |
| **接口**: 自动集成 20+ 优质影视资源站 API                 |
+-----------------------------------------------------------+

---

## 🔑 必填环境变量 (Environment Variables)

在部署平台的后台设置中添加以下变量：

+-----------------------------------------------------------+
| **PASSWORD**                                              |
| - 作用：登录面板的唯一凭证                                |
| - 默认：若不设置，则为 `whitefox`                         |
+-----------------------------------------------------------+
| **DB** (仅限 Cloudflare 部署)                             |
| - 作用：用于绑定 Cloudflare D1 数据库                     |
| - 要求：名称必须完全一致，设为 `DB`                       |
+-----------------------------------------------------------+

## 🚀 部署方式 (三分钟搞定)

### 方案 A：Cloudflare Pages (首选，支持 D1 同步)
1. **GitHub Fork** 本项目。
2. 在 Cloudflare 控制台选择 **Pages** -> **Connect to Git**。
3. **构建设置**:
   - 构建命令: `npm run build`
   - 输出目录: `dist`
4. **关键步骤**: 在项目 `Settings` -> `Functions` -> `D1 database bindings` 绑定名称为 `DB` 的 D1 数据库。

### 方案 B：Vercel 一键部署 (极速)
1. 点击 [Deploy to Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fyouruser%2Fwhite-fox&env=PASSWORD) (需替换 URL)。
2. 填写环境变量 `PASSWORD` 即可。

### 方案 C：直接上传 (静态部署)
1. 本地执行 `npm run build`。
2. 将 `dist` 目录内的文件整体上传至支持静态网页的服务器。
3. *注：此方式无法使用 D1 同步和内置代理，部分功能受限。*

## ❌ 为什么部署会失败？ (避坑指南)

1. **刷新页面 404**:
   - *原因*: 单页面应用 (SPA) 路由未重定向。
   - *解决*: 本项目已内置 `_redirects` 和 `vercel.json`，请确保它们在构建后的根目录。
2. **无法播放视频**:
   - *原因*: 资源站 API 存在跨域限制。
   - *解决*: 确保部署在 CF 或 Vercel，系统会自动调用内置 Proxy 解决跨域。
3. **无法保存历史/设置**:
   - *原因*: 数据库 D1 未初始化。
   - *解决*: 请在 CF 后台执行 `schema.sql` 脚本。
4. **构建速度慢或报错**:
   - *原因*: 依赖包下载失败。
   - *解决*: 确保 Node.js 版本 >= 18，推荐使用最新 LTS。
