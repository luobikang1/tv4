# 🦊 白狐影视 (White Fox TV)

一个功能强大、部署简便的开源影视项目。基于 React + Vite 开发，完美适配 Cloudflare Pages。

## ✨ 主要功能

- 📺 **全网采集**: 支持 AppleCMS 格式接口，内置 20+ 优质资源站，支持自动抓取。
- 🎬 **高清播放**: 集成 ArtPlayer，支持 HLS/m3u8 播放，可手动调节分辨率（低至 **360P**）。
- 🔒 **访问保护**: 设有独立的访问密码页面，保护隐私。
- ⚙️ **自定义接口**: 在设置面板中可自由添加、修改 API 接口。
- ☁️ **数据同步**: 支持调用 Cloudflare D1 数据库，实现设置与历史跨端同步。
- 🚀 **多平台支持**: 优化 Cloudflare Pages 部署，解决部署后无法访问的问题。

## 🚀 部署说明

### 方式一：GitHub 拉取部署 (推荐)

1. **Fork 本仓库**。
2. 在 Cloudflare 控制台新建 **Pages** 项目，选择 **Connect to Git**。
3. 构建配置：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. 在项目设置中绑定 **D1 数据库**（名称设为 `DB`）。
5. 环境变量中设置访问密码（可选）。

### 方式二：上传部署 (直接部署)

1. 下载项目中的 `dist` 文件夹压缩包。
2. 在 Cloudflare Pages 选择 **Upload assets**。
3. 将 `dist` 文件夹内的所有内容拖入上传区域。

## ⚠️ 注意事项与关键变量

请务必正确配置以下变量，否则可能导致功能失效：

### 关键变量

+-----------------------------------------+
| **DB**                                  |
| 说明：Cloudflare D1 数据库绑定名称      |
| 要求：**必须** 命名为 `DB`              |
+-----------------------------------------+

+-----------------------------------------+
| **PASSWORD**                            |
| 说明：访问面板所需的管理密码            |
| 默认：若未设置，默认为 `whitefox`       |
+-----------------------------------------+

### 部署注意事项

1. **数据库初始化**: 部署后，请务必在 D1 控制台执行 `schema.sql` 中的 SQL 语句以创建数据表。
2. **跨域问题**: 本项目通过内置的 `/api/proxy` 函数自动处理 API 跨域，无需额外配置代理服务器。
3. **SPA 路由**: 本项目已包含 `_redirects` 文件，解决了 Cloudflare 部署后刷新页面 404 的问题。
