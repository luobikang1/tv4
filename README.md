# 🦊 白狐影视 (White Fox TV) - 终极多端部署版

一个功能强大、性能卓越的开源影视项目。支持 **Cloudflare Pages**、**Vercel**、**Docker** 以及 **直接上传**。

---

## ✨ 核心特性

- 📺 **全站搜索**: 集合 20+ 资源站结果，一键找片，不再受限于单站。
- 🎬 **全能播放**: 支持 HLS/m3u8，分辨率覆盖 **240P - 1080P**。
- ⏩ **智能跳过**: 设定“跳过片头”秒数，全站视频自动生效。
- 🔒 **安全访问**: 内置密码锁，保护访问私密。
- 🌓 **双色模式**: 丝滑切换白天/夜间主题。
- ☁️ **云端同步**: 适配 Cloudflare D1，历史与设置永不丢失。
- 📥 **视频下载**: 播放器内置下载功能，喜欢的影片随心保存。

## 🚀 部署方案 (Choose Your Way)

### 1. Cloudflare Pages (推荐)
- **优势**: 免费、全球加速、支持 D1 数据库同步。
- **构建设置**:
  - 构建命令: `npm run build`
  - 输出目录: `dist`
- **变量设置**:
  ┌─────────────────┐
  │ **PASSWORD**    │ -> 面板密码
  ├─────────────────┤
  │ **DB**          │ -> 绑定 D1 数据库 (需在控制台手动绑定)
  └─────────────────┘

### 2. Vercel 部署
- **优势**: 配置最简，适合新手。
- **步骤**: 直接导入 GitHub 仓库 -> 设置 `PASSWORD` 环境变量。

### 3. Docker 部署
- **优势**: 独立、可控，适合 NAS 或自有服务器。
```bash
# 构建镜像
docker build -t white-fox .
# 运行容器 (设置密码为 123456)
docker run -d -p 3000:3000 -e PASSWORD=123456 white-fox
```

## ⚠️ 常见部署失败与解决方法

+--------------------------+------------------------------------------------------------+
| **错误现象**             | **根本原因与对策**                                         |
+--------------------------+------------------------------------------------------------+
| **视频加载失败**         | 跨域限制。确保部署在支持 Serverless (CF/Vercel) 或 Docker。|
+--------------------------+------------------------------------------------------------+
| **数据库保存报错**       | CF 环境未绑定 D1。在 Pages 设置 -> 函数 -> 绑定 D1 (名为 DB) |
+--------------------------+------------------------------------------------------------+
| **刷新页面 404**         | 路由重定向失效。确保 `_redirects` 或 `vercel.json` 已正确部署。|
+--------------------------+------------------------------------------------------------+
| **构建失败**             | 依赖不全或版本冲突。请确保 Node.js 版本 >= 18。            |
+--------------------------+------------------------------------------------------------+
